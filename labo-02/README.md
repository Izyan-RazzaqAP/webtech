## 2. Selectors lezen

Welke elementen raakt elke selector? Eén zin per selector.

- a. `header nav ul li a`: Alle links binnen een list item van een unordered list binnen de nav in de header.
- b. `article > p`: elke p die een direct kind is van het element article
- c. `.uren li:nth-child(3)`: het derde list item van alle lijsten van de class uren
- d. `h2 ~ p`: elke p onder een h2 binnen dezelfde ouder
- e. `.rassen li:first-child`: het eerste list item van alle lijsten van de class rassen
